# How to Generate the Boutiqo PDF

## Step 1 — Save your screenshots

Save each screenshot into the `screenshots/` folder with these exact filenames:

| File name | Screenshot to use |
|---|---|
| `01-login.png` | The login / sign-in screen |
| `02-orders-list.png` | Orders list (266 orders total) |
| `03-order-detail.png` | Order detail with payment history (Deepa Nair) |
| `05-customers-list.png` | Customers list (31 customers) |
| `06-customer-profile.png` | Customer profile with orders (Ananya Patel) |
| `07-measurements-list.png` | Measurements list with Copy & Share buttons |
| `08-measurement-detail.png` | Measurement detail (fields grid — Churidar, Blouse) |
| `10-staff.png` | Staff management screen |

## Step 2 — Open in browser

Open `boutiqo-brochure.html` in **Google Chrome** or **Safari**.

## Step 3 — Print to PDF

1. Press `Cmd + P` (Mac) or `Ctrl + P` (Windows)
2. Set destination: **Save as PDF**
3. Paper size: **A4**
4. Margins: **None**
5. Enable **"Background graphics"** (important for colors!)
6. Click Save

---

The PDF will be 8 pages, ready to share with boutique owners.
